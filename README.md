## Why your code didn't apply, and the order to check it in

Almost every failed code is one of three things: it does not cover the plan in your cart, the window has closed, or it is fighting another discount. Work through them in this order.

1. **Plan eligibility.** `JUSTVIBE` only covers AI-ready VPS, `PRIVATE` only covers the personal VPN, and `CLASSIC35` only covers classic KVM VPS plans in the nine locations listed in the campaign (Frankfurt, Amsterdam, Stockholm, Los Angeles, London, Tokyo, Helsinki, Sofia, Atlanta). A code for one product line does nothing on another.
2. **The campaign date.** This is the one that probably applies right now. The promotion closed on October 31, 2026. An expired code can look accepted in the field and still fail at payment.
3. **Stacking.** The terms state that promo codes cannot be combined with other discounts. The site already discounts 12-month orders by 20%, so the cart may apply one and drop the other, or reject the code outright. Whichever it does, compare the final total to the total without the code rather than trusting the badge.
4. **Typos and case.** `CLASSIC35` is not `CLASSIC2026`; `JUSTVIBE` has no hyphen. Copy and paste it.
5. **Browser state.** A cached cart can hold an old price. Try a private window before you open a ticket.

If all five are clean and the discount still does not appear, support can confirm in a minute whether the code is dead or the plan is excluded. None of this is unusual for VPS coupons; the same three failure modes show up across the industry, which is why a code should be treated as a bonus on top of a price you would pay anyway.

Skip the $1.99 promo box if you need to send mail from the server, if you already run another VPS with the host, or if you want a machine for longer than a month and dislike surprises: the recurring rate is not published on the plan page.
